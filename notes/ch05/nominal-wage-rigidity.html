CH. 05 / AGGREGATE SUPPLY

名目工資僵固與短期產出

合約鎖住的是名目薪資。物價變動後，企業面對的實質勞動成本會跟著改變。

  • 推導名目工資僵固下的向上 SRAS 機制
  • 辨認工資調整後模型的限制
概念理解公式與假設逐步推導例題與練習常見錯誤考前重點參考資料

先備知識：實質工資與效率工資；基本代數（效率工資微分可搭配文字與圖形意義閱讀）。

01概念理解

名目工資僵固（Nominal wage rigidity）指名目薪資在短期內不易調整，例如企業與工會的長期合約。當名目工資 W 固定而物價 P 上升，實質工資 W/P 降低；在其他條件不變、企業可增加僱用時，勞動需求與產出可能增加。這是教材第 25 頁的短期總供給機制。

換個角度理解 · 生活譬喻

烘焙坊先簽好每小時 200 元的薪資合約，之後產品售價上升。每小時薪資可換算成的產品數下降，對應企業實質勞動成本下降。

譬喻的限制：單一店家的售價不等於總體物價；原料成本、需求或產能限制也可能同時改變。譬喻只隔離固定名目工資這一條機制。

02公式與假設

短期 W 固定；固定技術與資本，邊際勞動生產力隨僱用下降，企業可以調整僱用，且需求足以支持所討論的產量。自編生產函數及其勞動需求僅用來演示，不是老師指定方程式；採價格接受、實質利潤最大化。

w=WP實質工資定義
Y = 20√N；Nᴰ = (10/w)²自編生產模型：利潤最大化條件 MPL = w，固定資本與技術
符號意義與單位
W名目工資；名目貨幣／人期
P物價指數；以基期 1 表示
w實質工資；基期貨幣／人期
Nᴰ、N勞動需求與實際僱用；人
Y每期實質產出單位；本題 Y = 20√N，邊際產出遞減

03逐步推導

  1. 固定 W 時，P 上升使分母變大，所以 w = W/P 下降。
  2. 在向下的勞動需求曲線上，實質工資下降對應較高僱用；這是沿既有勞動需求曲線移動。
  3. 技術及資本固定時，更多勞動可增加產出，形成 P 與 Y 的正向短期關係。
  4. 自編生產函數 Y = 20√N 的邊際產出為 MPL = 10/√N。由 MPL = w，得 √N = 10/w，所以 N = (10/w)²。再代入 w = W/P，得 N = (10P/W)²、Y = 200P/W。
  5. 固定 W 下，P 上升使 200P/W 上升，因此 Y 上升；若工資合約重訂，W 不再固定，不能繼續沿用同一條曲線。

04例題與練習

EXAMPLE / 例題

自編例題：W = 1，P 從 1 升到 1.25。依 N = (10/w)²、Y = 20√N，求兩種物價下的實質工資、僱用與產出。

查看解答與步驟
  1. P = 1：w = 1，N = (10/1)² = 100 人，Y = 20√100 = 200 單位／期。
  2. P = 1.25：w = 1/1.25 = 0.8，N = (10/0.8)² = 156.25 人的勞動等值，Y = 20 × 12.5 = 250 單位／期。勞動可連續分割，非指實際僱用四分之一個人。
  3. 驗算 Y = 200P/W：分別為 200、250；MPL 分別為 1、0.8，等於對應實質工資。名目工資未變，但實質工資下降，僱用與產出增加。
YOUR TURN / 換你練習

自編練習：若 P = 1.25 時，重新議約將 W 提高至 1.25，依相同模型，僱用與產出是多少？

查看解答與步驟

先算 w = 1.25/1.25 = 1，再得 N = (10/1)² = 100 人、Y = 20√100 = 200 單位／期。驗算 200P/W = 200 × 1.25/1.25 = 200。工資隨物價等比例調整，原先實質成本下降的效果消失；這次 W 改變，不能解釋為沿原本固定 W 的 SRAS 移動。

05常見錯誤

物價升 25%，實質工資就降 25%

固定 W 時 w 變成原來的 1/1.25 = 0.8。

正確判斷 → 精確降幅為 20%，不要混用百分比。

實質工資下降一定使全體產出增加

結論依賴可增僱用、技術及需求等條件。

正確判斷 → 先列模型假設。

名目工資僵固永久成立

合約會到期並重新議定。

正確判斷 → 把這條機制限定在短期。

06考前重點

  • 固定 W、P 上升 → W/P 下降 → 僱用與產出增加。
  • 固定的是名目工資，不是實質工資。
  • 工資重訂會改變供給條件。
