CH. 04 / THE IS CURVE

IS：商品市場的均衡

為什麼利率降低，能讓較高的產出與商品市場均衡相容？

課堂第 4 章對照講義第 9–12 頁更新 2026-11-15
讀完這一頁，你應該能夠
  • 由商品市場均衡推導向下傾斜的 IS
  • 區分沿 IS 移動與整條 IS 位移
概念理解公式與假設逐步推導例題與練習常見錯誤考前重點參考資料

先備知識：景氣循環的方向與時序；基本代數運算。

01概念理解

IS 曲線列出使商品市場均衡的產出與實質利率組合。在封閉經濟中，Y = C + I + G 可改寫為國民儲蓄 S = Y − C − G = I。課堂從儲蓄與投資圖推導；下方用自編線性支出模型呈現同一均衡條件。

換個角度理解 · 生活譬喻

企業像在比較是否要借錢開新店：利率較低，更多投資計畫變得划算；新增訂單使企業增產，並帶動所得與消費。

譬喻的限制：利率不是投資的唯一因素；預期、融資限制與風險也有影響。本頁固定這些條件，並假設短期產出能回應需求。

02公式與假設

封閉經濟、短期固定物價、定額稅 T；C = C₀ + c(Y − T)，0 < c < 1；I = I₀ − br，b > 0。r 以小數表示，G、T、C₀、I₀ 視為外生。

Y=C+I+G商品市場均衡條件
A=C0−cT+I0+G自發支出合計
(1−c)Y=A−brIS 的線性形式
r=[A−(1−c)Y]/bY 與 r 呈負向關係
符號意義與單位
Y、C、I、G、T每期實質產出、消費、投資、政府支出、稅
C₀、I₀自發消費與投資
c邊際消費傾向；無單位
b投資對小數利率的反應係數
r、A實質利率；自發支出合計

03逐步推導

  1. 代入均衡式：Y = C₀ + c(Y − T) + I₀ − br + G。
  2. 展開並把 cY 移至左側：(1 − c)Y = C₀ − cT + I₀ + G − br。
  3. 以 A 代表不隨 Y、r 變動的自發支出，得到 (1 − c)Y = A − br。
  4. 固定 A 時，r 上升使投資與均衡產出下降，形成向下 IS。
  5. G 或自發支出增加使 A 增加，IS 右移；T 增加使 A 減少，IS 左移。

04例題與練習

EXAMPLE / 例題

自編例題：C = 100 + 0.8(Y − 100)，I = 100 − 1,000r，G = 80。求 IS，並求 r = 0.04 時的 Y。

查看解答與步驟
  1. A = 100 − 0.8 × 100 + 100 + 80 = 200。
  2. 0.2Y = 200 − 1,000r，因此 Y = 1,000 − 5,000r。
  3. r = 0.04 時，Y = 800。
  4. 驗算：C = 660，I = 60，G = 80；合計 800 = Y。
YOUR TURN / 換你練習

自編練習：維持同一模型且 r = 0.04，G 增加 20，Y 變成多少？請說明移動的是曲線還是曲線上的點。

查看解答與步驟

A 增至 220，Y = 1,100 − 5,000r，代入得 Y = 900。C = 740、I = 60、G = 100，合計 900。G 改變使 IS 右移；增加 100 是固定利率下的結果，聯立傳統 LM 後須重新求解。

05常見錯誤

降息使 IS 右移

利率原本就是座標軸變數。

正確判斷 → 其他條件固定時，降息是沿 IS 移動。

S = I 表示每個人的存款等於投資

這裡是總體的期望國民儲蓄與投資均衡。

正確判斷 → 區分國民儲蓄與個人銀行存款。

政府支出乘數永遠是 1/(1−c)

聯立 LM 後利率可能上升。

正確判斷 → 先確認固定利率還是固定貨幣供給。

06考前重點

  • IS：商品市場均衡；傳統座標為橫軸 Y、縱軸 r。
  • 利率變動是沿曲線移動；自發支出變動才是位移。
  • 課堂儲蓄投資圖與本頁代數推導描述同一均衡。
